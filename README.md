# 夜航练习室

两种练习方式：

- **双声部接唱**（默认）：两个声部先后重叠，双方的词和入口同屏。选句或开
  「接头循环」会把重录锁在同一个接头上；录完可以拿已知的对方导唱轨判断哪段
  确实有我开口、哪段主要是串音，重叠同音而证据不足时标为「无法判断」。
- **单声部跟唱**：原有的整首跟唱与逐句录音。

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。

## 双声部接唱怎么用

1. 选练习（`回声练习` / `交叠练习`）与「我唱低声部 / 我唱高声部」。扬声器里放的
   是对面那一轨，屏幕上是双方的歌词与各自的入口。
2. 选一句，或点「接头循环」。录音总是从入口前 0.9 秒开始，抢拍的声音不会被剪掉。
3. 录完自动进入「原始复听与对照」：
   - **原始复听**：未经任何处理的麦克风原声；对方导唱只是叠加上去的播放层。
   - **对照证据**：时间线上逐段标出「确实有我 / 主要是串音 / 无法判断 / 只有底噪」，
     下面按实际覆盖列出「按入口 / 抢拍 / 循环内重入 / 拖尾」。
4. 拖动「导唱」滑块只改变复听时叠加的音量。每条证据都记着它被判定时的导唱音量，
   改音量不会改写旧证据。

### 判断依据

扬声器会串进麦克风，所以单靠「现在轮到谁唱」不能判断。分析只用两样东西：麦克风
录音，和**已知的**对方导唱轨。

- 先把已知导唱轨和录音对齐（波形互相关），估计传播延迟和串音耦合系数；
- 从麦克风里减掉按该系数预测的串音，得到残差；
- 残差高于噪声底，并且落在**我这一声部**的音高上（含 ±12 度的轻唱）才算「确实有我」；
- 残差与对方导唱同步、扣掉后几乎没有剩下，判为「主要是串音」；
- 双方同音时，已知串音已经能解释电平，无法区分是否还有我的声音，标为「无法判断」，
  绝不按角色时段推断；
- 角色时段内麦克风始终接近底噪时标「只有底噪」，而不是默认记成我唱的。

证据在录音结束时一次性算好并随录音冻结保存；以后无论导唱音量改成多少，回看的
都是当时的判定。

### 验证样本

没有麦克风也能验证：在「本接头录音」里点「载入验证样本」。样本由已知的两个声部
合成，覆盖弱 / 强串音、高八度轻唱、抢拍进入、循环内重入、双方同音六种情况。

## 开发脚本

```sh
npm run typecheck     # vue-tsc
npm run build         # vite build
npm test              # 证据分析、几何与示例样本的单元测试（esbuild + node --test）
npm run test:ssr      # 用 Vite SSR 渲染组件，检查模板/接线（不是浏览器测试）
node scripts/generate-duet-guides.mjs   # 重新生成双声部导唱 wav 与练习数据
```
